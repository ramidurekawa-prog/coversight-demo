# Coversight UX Quality Report: 2026-11-23

Scores use `docs/QUALITY_SCORECARD.md`, an editorial rubric, not a measured benchmark. Every score below comes from screenshots and scripted browser runs on this branch, listed further down.

## Scope and environment
- **Start:** `main` at 2d5492c (merge of PR 74), no local changes.
- **Routes inspected in a browser:** `/today`, `/service`, `/labour`, `/inputs` (Add & Manage Data), at 1440, 768 and 390 px wide.
- **Runtime:** `pnpm dev` (Next.js 16.4.5), `http://localhost:3000`, no `DATABASE_URL`, so the app runs in browser-only demo mode on the sample group. Sign-in, Postgres, Toast and 7shifts paths were not run.
- **Design resources:** see "Tools" below.

## The release-gate failure on main
`main` did not compile. `components/kit.jsx` imported and exported `Minus` twice after PRs 64, 71 and 74 merged on top of each other. Every page returned a 500 in dev, and `pnpm test` failed 4 of 45 test files. That is one line, fixed here, and there is now a GitHub Actions check (`.github/workflows/check.yml`) that runs typecheck, tests and build on every PR so this can't merge silently again.
